## Experimental v2.2.9 bundle

**Important:** The existing `v2.2.9` tag points to older, unbuildable source;
the attached bundle is built from the separate, corrected source commit linked
below. The tag has not been moved. The main-branch patch catalog remains older
until the source changes are merged; importing the attached bundle is the
reliable way to use this build.

### Implemented, but unverified

- WhatsApp: 10 opt-in wrappers around shared heuristics, including analytics,
  ads, external browser, screen capture, permission removal, autoplay,
  logging, telephony identifiers, and usage data.
- Proton Pass: screenshot allowance and telemetry/ad heuristics, plus the
  existing local-only Unlimited Plan patch with a constructor-layout guard.
- Table Notes: three opt-in wrappers for analytics, ads, and external browser.
- Universal **Block ads & ad SDKs**: removes recognizable void SDK load/show
  call sites. It can miss ads and may break rewarded-ad workflows.

These heuristics are not guaranteed to match anything. No target APK or device
has been tested for these new app entries. The two WhatsApp screen-capture
patches conflict; choose at most one. Permission removal can break registration,
calls or media. The Proton plan patch does not change server entitlements.

### Unimplemented placeholders — do not select

The seven WhatsApp entries for deleted messages, read receipts, typing, view-once
media, icon, and mods settings entry/resources are placeholders. **All seven new
Proton Pass feature entries are placeholders too**: upgrade nag UI, auto-lock,
clipboard auto-clear, multiple vaults, biometric always-on, password generator
options, and dark-web monitoring. They make no changes and intentionally fail
if selected; the dark-web entry performs no monitoring. All are off by default.

The bundle was compiled and checked by CI, including synthetic bytecode tests;
this is not device verification. See the source documentation for details.
